# Task 5. Charles Proxy

## Sniffer funksiyalari

### So‘rovlarni filtrlash
Faqat kerakli so‘rovlarni (domen, metod yoki kalit so‘z bo‘yicha) kuzatish imkonini beradi.

### Loglar bilan ishlash
Ilovaning barcha tarmoq so‘rovlarini yozib borish va tahlil qilish.

### Shifrlangan trafik bilan ishlash
**SSL Proxying** qo‘llab-quvvatlashi orqali HTTPS-trafikni ko‘rish (sertifikat o‘rnatgandan so‘ng).

### Map Remote
Bitta URL’ni boshqa URL’ga yo‘naltirish (masalan, turli muhitlarda test qilish uchun).

### Breakpoint
So‘rovni jo‘natish yoki javob olishdan oldin to‘xtatish → qo‘lda o‘zgartirish mumkin.

### Rewrite
Avtomatik ravishda so‘rov yoki javoblarni oldindan belgilangan qoidalarga ko‘ra o‘zgartirish.

### Throttling
Tarmoqqa sun’iy ravishda sekinlik berish (masalan, 3G yoki yomon Wi-Fi’ni taqlid qilish).
