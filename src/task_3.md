# Task 3. Xcode’da emulyator yaratish

## Xcode o‘rnatish
1. Mac App Store’ni oching.  
2. Qidiruv oynasiga **Xcode** deb yozing.  
3. Xcode’ni yuklab olib, o‘rnating.  

## Simulyator komponentlarini sozlash
1. Xcode’ni ishga tushiring.  
2. Menyudan **Xcode → Preferences** bo‘limiga o‘ting.  
3. **Components** tabini tanlang.  
4. Bu yerda kerakli **iOS Simulator** versiyalarini yuklab oling (masalan, iOS 16.4).  

## Simulyatorni ishga tushirish
1. Menyudan **Xcode → Open Developer Tool → Simulator** ni tanlang.  
2. Ochilgan oynada **Device → iOS Version → Qurilma modeli** (masalan, *iPhone 14 Pro*) ni tanlang.  
3. Simulyator ishga tushadi va qurilma oynasi ekranda paydo bo‘ladi.  

## Test qilish
- Endi siz yaratilgan emulyator orqali iOS ilovalarini ishga tushirishingiz va test qilishingiz mumkin.  
- Xcode orqali **Build & Run** qilsangiz, tanlangan simulyatorda dastur ochiladi.
